## 18.10.2026 · 1c-odata-mcp (github.com/evilbruce666/1c-odata-mcp)

**Статус:** идеи забираем (решение Славы), с автором не связываемся.

### Что это

- MCP-сервер для 1С через OData, MIT. Node.js 20+ / TypeScript, `npx -y 1c-odata-mcp`, stdio, локальный процесс. В npm и Smithery, ~19 звёзд, ~100 коммитов.
- 56 инструментов: 21 чтение/аналитика (дебиторка, остатки, продажи, движение денег, налоги, история по контрагенту), 35 запись (контрагенты, счета, реализации, оплаты, ПКО/РКО, счета-фактуры, копирование, **проведение**).
- Несколько баз (`database`) и организаций (`organization`). Запись выключена по умолчанию, два флага + dry-run → `confirm=true`.
- Проверен на БП 3.0 **РФ**: счета 62/41/51 зашиты в аналитику.

### Сравнение

| | 1c-odata-mcp | Bilem Agent |
| --- | --- | --- |
| Онбординг | вручную по инструкции: публикация, состав OData, права на папку | автоматически за ~11 с |
| Права в 1С | ответственность пользователя | свой `bilem`, только чтение, проверено |
| Конфигурация | БП 3.0 РФ | БП КЗ («Типовой», БИН), профиль конфигурации |
| Установка | Node 20+, JSON-конфиг руками | один exe, окно, трей, «Подключить к Claude» |
| Периметр | нет | 127.0.0.1, токен, закрытые разделы |
| Запись | широкая, с проведением; подтверждение через модель | позже: черновик + кнопка мимо модели, без проведения ([0002](/decisions/0002-ne-trogaem-uchet)) |
| Облако, ChatGPT, голос | нет | платный режим |
| PDF, почта | нет | v0.3 |

**Вывод:** не соревнуемся числом инструментов. Наше отличие — то, на чём он останавливается: установка в один клик, Казахстан, безопасность по умолчанию, облако и голос.

### Что забираем и куда

| Идея | Зачем | Куда |
| --- | --- | --- |
| **Пробел в `$filter` — `%20`, не `+`** (1С на `+` отвечает 400) | поиск по фразам с пробелами | **сразу** — проверка в v0.1 ([правки, пачка 2](/stand/agent-app-v01-pravki)) + known-issues |
| **Лимиты выборок**: размер страницы и защитный максимум строк, усечение с пометкой | не выгружать тысячи строк в модель | правки v0.1, пачка 2 |
| **Имена `read.*` / `write.*`** (`read.analytics.get_debtors`) | сразу видно чтение/запись; удобно для периметра | v0.2 (каталог инструментов); старые имена — алиасами |

| **Карта базы**: `list_entities` / `describe_entity` из `$metadata` + вежливая подсказка «объект не в составе OData» | ответ на нестандартные вопросы | v0.2 |
| **`health_check`** — «проверь соединение с 1С» | первый вопрос после подключения | v0.2 |

| **Реквизит «Содержание» в строках** | именно он печатается в счёте/акте, 1С сама его через OData не заполняет | v0.3 + шаблон PDF |
| **Счета учёта из регистра «Счета учёта номенклатуры»**, с откатом на стандартные | через OData их не подставляет форма 1С — без них документ «кривой» | v0.3 (рецепт документов) |
| **Банковский счёт организации** по умолчанию — основной, можно указать | реквизиты для оплаты в счёте | v0.3 |
| **README под запросы** («как подключить 1С к нейросети»), демо-диалог картинкой, FAQ, Smithery / npm-аналоги, GitHub topics | находимость | [ИИ-находимость](/product/ai-nakhodimost) |
