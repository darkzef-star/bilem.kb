## Имя

**Bilem** — от казахского «білем» («знаю»; разг. от «білемін»; кыргызское «билем», узбекское «bilaman»). Читается латиницей без ловушек во всех трёх странах.

## Логотип

₸ в пузыре сообщения, в зелёном круге. Знак говорит три вещи сразу: деньги (тенге), разговор (мессенджер), Казахстан.

|---|---|
| [mark.svg](/images/brand/mark.svg) | знак без надписи: фавикон, аватар, иконка приложения |
| [wordmark-light.png](/images/brand/wordmark-light.png) | знак + bilem.ai на светлом фоне |
| [wordmark-dark.png](/images/brand/wordmark-dark.png) | знак + bilem.ai на тёмном фоне |

| [avatar-640.png](/images/brand/avatar-640.png) | аватар WhatsApp / Telegram / соцсетей |

<Warning>
  Не перекрашивать знак, не вытягивать, не класть зелёный круг на зелёный фон. Вокруг знака — поле не меньше половины его высоты. Векторный вордмарк (SVG) пока не сделан — есть только PNG 1260×360.
</Warning>

## Голос

<AccordionGroup>
  <Accordion title="Интерфейс к базе, не собеседник" icon="database">
    Каждый ответ — из 1С, с источником и датой (`as_of`). Нет данных — честно: «білмеймін», «в базе этого нет». Знания о мире и интернет не используем.
  </Accordion>
  <Accordion title="Коротко, текстом, по делу" icon="align-left">
    Отвечаем текстом, даже если спросили голосом — читается быстрее, чем слушается. Цифра первой строкой, детали ниже. Без эмодзи-гирлянд и «Отличный вопрос!».
  </Accordion>
  <Accordion title="Тон «швейцарского банка»" icon="building-columns">
    О данных: «никому ничего не передаём, не продаём, не храним дольше обработки, не обучаем». Точка. Не оправдываемся и не объясняем внутреннюю кухню без запроса.
  </Accordion>
  <Accordion title="Не навреди учёту" icon="shield">
    Обещание жирным везде: Bilem не проводит документы и не делает платёжки. Подробнее — [0002](/decisions/0002-ne-trogaem-uchet).
  </Accordion>
  <Accordion title="Два языка" icon="language">
    Русский и казахский на равных. Казахский текст проверяет лингвист. Термины — по словарю `glossary.md` в Brain.
  </Accordion>
</AccordionGroup>
