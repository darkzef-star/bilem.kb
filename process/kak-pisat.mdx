База — это обычные `.mdx`-файлы в приватном репо `skp-kz/bilem.kb`. Mintlify собирает из них этот сайт через минуту после коммита. Каждое изменение остаётся в истории GitHub — это и бэкап, и откат.

<Tabs>
  <Tab title="На сайте">
    Кнопка редактирования на странице или [дашборд Mintlify](https://app.mintlify.com) → Editor. Публикация = коммит в `main`.
  </Tab>
  <Tab title="Через git">
    ```bash
    gh repo clone skp-kz/bilem.kb
    # правишь .mdx, новая страница — добавь её в docs.json → navigation
    git add -A && git commit -m "решения: 0005 …" && git push
    ```
    Локальный предпросмотр: `npx mint dev` → http://localhost:3000
  </Tab>
  <Tab title="Через MCP">
    **Читать** (поиск по базе):
    ```bash
    claude mcp add --transport http bilem-kb https://<домен базы>/authed/mcp
    ```
    **Писать** (admin MCP Mintlify — правки, новые страницы, PR):
    ```bash
    claude mcp add --transport http mintlify https://mcp.mintlify.com
    ```
    При первом вызове откроется браузер — вход в аккаунт Mintlify.
  </Tab>
</Tabs>

## Что куда

| Папка | Что | Пример |
|---|---|---|
| `product/` | Что строим и зачем | позиционирование, тарифы |
| `decisions/` | Одно решение — одна страница, номер по порядку | `0005-…mdx` |
| `cfe/` | Контракт, роли, каталог | спека эндпоинтов |
| `onec/` | Знания про 1С и БП КЗ | HTTP-сервисы, имена объектов |
| `stand/` | Стенд и доступы | что стоит, первый день |
| `process/` | Как работаем | цикл задачи, ревью |
| `meetings/` | Заметки созвонов, `ГГГГ-ММ-ДД.mdx` | итоги, договорённости |
