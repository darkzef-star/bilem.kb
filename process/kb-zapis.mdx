Одно правило для всех: Cowork Славы (навык `kb-zapis`), Земля и Воздух (команда `/kb` в Claude Code), Станислав, Куралай. Фраза «занеси в базу знаний» или `/kb` — агент заносит то, о чём сейчас шла речь, по этим правилам и присылает ссылку.

## Что и куда

| Тип | Куда (вкладка → группа) | Путь |
|---|---|---|
| Решение | База → Решения | `decisions/NNNN-slug` — следующий свободный номер |
| Встреча / созвон | Стенд и процесс → Встречи | `meetings/YYYY-MM-DD` (вторая за день — `-2`) |
| Задача агенту, инструкция по стенду | Стенд и процесс → Стенд | `stand/slug` |
| Журнал работ по задаче | Стенд и процесс → Стенд | `stand/slug-log`, новые записи сверху |
| Как работаем, правила | Стенд и процесс → Как работаем | `process/slug` |
| Продукт: дорожная карта, тарифы, меню услуг | База → Продукт | обновить существующую страницу |

Если неясно, что именно заносить, — один короткий вопрос, иначе не спрашивать.

## Порядок

1. **Поиск** по ключевым словам. Есть подходящая страница — дополнить её (прочитать → записать целиком, ничего чужого не теряя), а не плодить дубль. Новое решение, меняющее прежнее, — новая страница + в старой строка «заменено решением NNNN» со ссылкой.
2. **Писать** по-русски, коротко, факты. Даты абсолютные (17.10.2026). Заголовок — только во frontmatter `title`, в тексте с `##`. `description` — одна строка.
   - Решение: «**Дата:** … · **Кто:** … · **Статус:** …», разделы «Решение», «Почему», «Что отвергли / отложили», «Что из этого следует».
   - Встреча: участники, итоги, решения, кто что делает и к какому сроку.
   - Задача агенту: контекст, исходные, шаги, что сдать, что нельзя.
3. **Опубликовать** сразу (разрешение Славы) и дождаться, пока изменения будут на сайте.
4. **Ответить** одной строкой: что занесено и куда + ссылка `https://kb.bilem.ai/<путь>`.

## Чего не заносить никогда

Пароли, токены, ключи, секреты (даже «учебные» — писать «пароль сообщит Слава»), персональные данные, данные клиентов и содержимое баз 1С (в том числе учебных), выписки и суммы клиентов. Внутренние адреса стенда и имена машин — можно (база закрыта авторизацией), секреты к ним — нет.

## Команда /kb для Claude Code

Земля, Воздух, Станислав: создайте у себя файл пользовательской команды Claude Code и вставьте в него текст ниже.

- Windows: `C:\Users\<пользователь>\.claude\commands\kb.md`
- Linux / macOS: `~/.claude/commands/kb.md`

```markdown
---
description: Занести в базу знаний Bilem (kb.bilem.ai)
---
Занеси в базу знаний Bilem то, о чём сейчас шла речь (или: $ARGUMENTS).
Правила — страница process/kb-zapis в базе знаний (MCP Mintlify, деплой bilem-ai): прочитай её и выполни по ней —
тип и раздел, поиск дубля, формат, без секретов и данных 1С, публикация, в ответ одна строка со ссылкой.
```

После этого в любой сессии: `/kb` или `/kb решение про права пользователя bilem`.
