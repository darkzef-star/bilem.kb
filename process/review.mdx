title: "Ревью в три шага"
description: "Смержить то, что сгенерировал агент, — не ревью."
icon: "magnifying-glass"
---

<Steps>
  <Step title="Агент-ревьюер">
    Claude Code сам проверяет свой PR суб-агентом: «проверь ветку против CLAUDE.md и контракта — граница учёта, привилегированный режим, коды ошибок».
  </Step>
  <Step title="Глаза человека">
    Слава читает дифф в GitHub: что изменилось, нет ли проведения и записи в регистры, понятны ли сообщения ошибок.
  </Step>
  <Step title="Приёмка curl">
    Запрос по спеке на стенде — ответ совпадает с контрактом. Бот для приёмки не используем.
  </Step>
</Steps>

## Чек-лист

- [ ] Нет `Провести`, `Записать(РежимЗаписиДокумента.Проведение)`, движений регистров
- [ ] Нет `УстановитьПривилегированныйРежим`
- [ ] Ошибки — коды и формат из контракта, текст по-русски
- [ ] В ответе есть `as_of`
- [ ] Выгрузка `src/` актуальна, бинарного `.cfe` нет
- [ ] PR закрывает issue: `Closes #N`
