**Bilem** — агент по 1С для директора: отвечает про деньги, долги и налоги, выписывает счёт и акт сверки по данным базы клиента. Ядро — расширение `bilem.cfe`: REST и MCP в одном.

<Warning>
  **Граница «не навреди учёту».** cfe не проводит документы и не делает платёжки — таких методов нет в коде. Только чтение и непроведённые документы продажника.
</Warning>

<Tip>
  **Агент?** Начни со страницы [Для Claude Code — начни здесь](/process/dlya-claude-code).
</Tip>
