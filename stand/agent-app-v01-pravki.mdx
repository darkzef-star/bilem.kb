## Пачка 2 — 18.10.2026

<Steps>
  <Step title="Иконка на панели задач мутная — чёткость и DPI">
    Слава: в трее иконка хорошая, а на панели задач — «пиксельная, плохо отрисована».

    - **Новый `assets/icons/bilem-agent.ico`** (коммит Славы через веб, `git pull`): размеры 16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 128, 256 — под любой масштаб экрана (100–250 %), чтобы Windows брала готовый размер, а не растягивала соседний.
    - **Включить DPI-осведомлённость**, иначе Windows растягивает всё окно битмапом и иконка мылится: в манифесте `<dpiAwareness>PerMonitorV2</dpiAwareness>` (+ `<dpiAware>true/pm</dpiAware>` для старых систем), в `app.config` — `System.Windows.Forms.ApplicationConfigurationSection` → `DpiAwareness = PerMonitorV2`; проверить, что вёрстка окон не поехала на 125 % и 150 %.
    - Иконку формы грузить из ресурса **целиком** (`new Icon(stream)`), не через `Icon.ExtractAssociatedIcon` (он отдаёт только 32 px) и не одним размером. Для панели задач Windows сама выберет большой размер.
  </Step>
  <Step title="Иконка во всех окнах, не только в главном">
    Скриншот Славы: окно «Добавить базу 1С» — со стандартной иконкой Windows. **Все** окна и диалоги (добавить базу, настройка с шагами, диагностика, сообщения, «О программе») — с иконкой приложения. Проще всего: общий базовый класс формы, который ставит `Icon` из ресурса; тест — что у каждой формы `Icon` не стандартный.
  </Step>
  <Step title="Пробел в $filter — %20, не +">
    Из разбора конкурента ([Конкуренты](/product/konkurenty)): 1С не декодирует `+` как пробел внутри `$filter` и отвечает 400. Проверить, что `find_counterparty` с фразой из нескольких слов («Пример Клиент») работает; сборка строки запроса — `Uri.EscapeDataString` (пробел → `%20`). Тест + строка в known-issues.
  </Step>
  <Step title="Лимиты выборок">
    Размер страницы и защитный максимум строк на любой инструмент (по умолчанию 200 строк в ответе); если обрезали — в ответе пометка «показаны первые N из M, уточните запрос». Чтобы не выгружать в модель тысячи строк.
  </Step>
</Steps>

## Пачка 1 — 18.10.2026

<Steps>
  <Step title="Иконки — уже в репо">
    В `assets/icons/` (коммит Славы через веб, сделай `git pull`):

    - `bilem-agent.ico` — иконка приложения: exe (`ApplicationIcon`), окна, ярлыки, панель задач. **Всегда зелёная, не меняется.**
    - `tray-green.ico`, `tray-yellow.ico`, `tray-red.ico`, `tray-grey.ico` — **только для значка в трее** (16–64 px): тот же знак, перекрашенный целиком — на 16 px читается лучше, чем маленькая точка;
    - `app-512.png` — для README и сайта.

    Знак — фирменный знак Bilem (зелёный круг `#1FAF5A`, белое облачко). Иконки — встроенными ресурсами exe, не отдельными файлами рядом.
  </Step>
  <Step title="Статус в трее — цветной круг, без мигания">
    | Цвет | Смысл (формулировка Славы) | Когда именно | Подсказка при наведении |
    | --- | --- | --- | --- |
    | зелёный | работает хорошо | MCP слушает, все базы проходят проверку | «Bilem Agent — работает · баз: N» |
    | жёлтый | подключение, «застряла» | запуск, настройка базы, проверка; **если дольше 60 с — переходит в красный** с причиной «долго нет ответа» | «Bilem Agent — подключение…» |
    | красный | ошибка, что-то не завелось | MCP не смог запуститься (порт занят и т. п.) или хотя бы одна база с ошибкой | «Bilem Agent — ошибка: …» (коротко что) |
    | серый | офлайн | нет подключённых баз **или** MCP остановлен пользователем | «Bilem Agent — офлайн: базы не подключены» / «MCP остановлен» |

    Смена значка — только при смене состояния, никакой анимации. Двойной щелчок — открыть окно; меню по правой кнопке: «Открыть», «Скопировать адрес MCP», «Выход».
  </Step>
  <Step title="Не терять окно и ярлыки">
    - при первом запуске окна — ярлык **«Bilem Agent» на рабочем столе** и в **меню «Пуск»** (для всех пользователей), с иконкой приложения; + CLI `bilem-agent shortcut`;
    - крестик окна — свернуть в трей, MCP работает дальше; **один раз** уведомление «Bilem Agent работает в трее — значок справа внизу (может быть под стрелкой ˄)»; завершение — только «Выход» в меню трея;
    - повторный запуск exe — не второй экземпляр, а показ уже работающего окна.
  </Step>
  <Step title="Версия в строке состояния">
    Внизу — **«Версия 0.1.0»** (из версии сборки). Слева: «MCP работает · порт 8796 · баз: 2», версия — справа.
  </Step>
  <Step title="Вкладка «Подключение» → «MCP»">
    Переименовать вкладку в **«MCP»** — в ресурсах и доках тоже.
  </Step>
</Steps>

## Приёмка

- Пачка 1: ярлыки с зелёной иконкой; крестик → трей, двойной щелчок → окно; второй запуск → то же окно; четыре цвета трея живьём (снимки в журнал); версия в строке состояния; вкладка «MCP».
- Пачка 2: иконка на панели задач чёткая на 100 %, 125 %, 150 % (снимки); у всех окон и диалогов — иконка приложения; поиск контрагента по фразе с пробелом работает; длинная выборка обрезается с пометкой.
- Коммиты по правилам репо, хеши — в журнал v0.1.
