## Пачка 5 — 18.10.2026 · подключить несколько баз за раз

Сейчас «Добавить базу 1С» уже показывает базы из списков 1С (`ibases.v8i`), но подключает по одной. Нужно: **отметить галочками нужные — «Подключить выбранные» — агент сам по очереди подключает все.** Проверять будем и на боевом сервере Славы с его базами (позже, на копиях эталона — сейчас).

<Steps>
  <Step title="Список баз">
    - Источники: `ibases.v8i` **всех** профилей пользователей + общие списки из `1CEStart.cfg`; одна и та же база из разных профилей — одной строкой (по пути / `Srvr+Ref`).
    - Колонки: галочка · название из списка 1С · путь (или сервер/база) · тип (файловая / серверная) · состояние («уже подключена» — серым, без галочки; «нет файла 1Cv8.1CD» — красным).
    - Серверные базы — видны, но **серые с пометкой «скоро»** (v0.1 — только файловые).
    - Кнопки: «Выбрать все», «Снять все», «Указать папку вручную…», **«Подключить выбранные»**.
  </Step>
  <Step title="Пароли администраторов">
    После «Подключить выбранные» — одно окно с таблицей выбранных баз: логин и пароль администратора 1С **для каждой** (у разных баз — разные). Флажок «Одинаковые для всех» — один логин/пароль на всё. Пустой пароль — допустим. Ничего не сохраняется.
  </Step>
  <Step title="Пакетное подключение">
    - Базы подключаются **по очереди** (не параллельно: COM и лицензии 1С). Короткое имя каждой — из названия в списке 1С (латиница, без пробелов), конфликт имён — с номером.
    - Окно хода: список баз, у текущей — раскрытые шаги с галочками (как сейчас), у остальных — «ждёт / готово ✓ / ошибка ✗ — причина».
    - **Ошибка одной базы не останавливает остальные.** В конце — сводка «подключено 4 из 5», у ошибки — «что делать» из known-issues и кнопка «Повторить» для неудавшихся (снова спросит пароль только для них).
    - Каждая база — свой пул IIS, своя проверка (как в одиночном подключении).
  </Step>
  <Step title="Первый запуск">
    Если подключённых баз ещё нет — при первом открытии окна сразу показать этот список («Найдены базы 1С на этом компьютере — отметьте, какие подключить»). Закрыть можно, вернуться — «Добавить…» на вкладке «Базы 1С».
  </Step>
  <Step title="CLI">
    `bilem-agent list-found` — найденные базы (с признаком «подключена»); `bilem-agent setup --base <путь> --base <путь> … --admin <логин> [--password …]` — несколько баз за один вызов, сводка и код возврата 1, если хоть одна не подключилась.
  </Step>
</Steps>

## Пачка 4 — 18.10.2026 · компактное окно

Слава: при открытии окно слишком широкое, почти пол-экрана — для утилиты это лишнее; растягивать можно, но **по умолчанию — компактно**.

<Steps>
  <Step title="Размер по умолчанию">
    Стартовый размер — около **640 × 440** логических пикселей (при 100 %; с PerMonitorV2 из пачки 2 масштабируется сам), по центру экрана. Минимальный — около **560 × 380**. Растягивать и разворачивать — можно.
  </Step>
  <Step title="Вёрстка под узкое окно">
    Раскладка потоком (`FlowLayoutPanel` / `TableLayoutPanel`), не фиксированными координатами. На вкладке «MCP» кнопки в две строки: «Подключить к Claude Code · Claude Desktop · Cursor» и «Сменить токен · Остановить MCP». Длинные пояснения переносятся. Проверить все вкладки на минимальном размере и на 125 % / 150 %.
  </Step>
  <Step title="Запоминать, как оставил пользователь">
    Изменённые размер и положение — запомнить (настройка пользователя). Окно за пределами экранов — вернуть на основной. Сброс — к размеру по умолчанию.
  </Step>
</Steps>

## Пачка 3 — 18.10.2026 · вкладка «Сервис»

Порядок вкладок: **Базы 1С · MCP · Доступ · Журнал · Сервис · О программе** («Сервис» — предпоследняя; «Доступ к данным» переименовывается в «Доступ» по [ТЗ v0.2](/stand/agent-app-v02)).

<Steps>
  <Step title="Что уходит из «Журнала»">
    На «Сервис» переносятся «Диагностика компонентов» и «Собрать отчёт для поддержки». На «Журнале» остаются журнал и «Открыть папку журналов».
  </Step>
  <Step title="Состав вкладки «Сервис»">
    **Проверка и поддержка**

    - **«Диагностика компонентов»** (`bilem-agent doctor`).
    - **«Собрать системную информацию»** — сразу в буфер обмена + «Сохранить в файл…»: версия агента; Windows; .NET; платформы 1С и разрядность; COM-коннектор; IIS и компоненты; порт и состояние MCP; по каждой базе — короткое имя, тип, **конфигурация и версия**, БСП, число объектов OData, роли `bilem`, последняя проверка. **Без** паролей, токенов, путей к профилям и данных из 1С. CLI: `bilem-agent sysinfo`.
    - **«Собрать отчёт для поддержки»** (zip без паролей и токенов).
    - **«Сообщить о проблеме на GitHub»** → `https://github.com/skp-kz/bilem.agent/issues/new` + подсказка «системная информация уже в буфере».
    - Серым: **«Платная техподдержка появится в коммерческой версии. Сейчас — только через GitHub Issues.»**

    **Обновления** (заготовка)

    - «Установлена версия 0.1.0»; кнопка **«Проверить обновления»** — неактивная, рядом серым «Скоро: обновление в один щелчок».
  </Step>
  <Step title="Тексты">
    Все строки — в `Strings.resx`; кнопки — глагол + что делаем.
  </Step>
</Steps>

  <Step title="Пробел в $filter — %20, не +">

  </Step>
  <Step title="Лимиты выборок">
    По умолчанию до 200 строк в ответе; если обрезали — «показаны первые N из M, уточните запрос».
  </Step>
</Steps>

## Пачка 1 — 18.10.2026

<Steps>
  <Step title="Иконки">
    `bilem-agent.ico` — приложение (exe, окна, ярлыки, панель задач), всегда зелёная; `tray-green/yellow/red/grey.ico` — только трей. Встроенными ресурсами exe.
  </Step>
  <Step title="Статус в трее — цветной круг, без мигания">
    | Цвет | Смысл | Когда | Подсказка |
    | --- | --- | --- | --- |
    | зелёный | работает | MCP слушает, все базы в порядке | «Bilem Agent — работает · баз: N» |
    | жёлтый | подключение | запуск, настройка, проверка; **дольше 60 с → красный** | «Bilem Agent — подключение…» |
    | красный | ошибка | MCP не запустился или база с ошибкой | «Bilem Agent — ошибка: …» |
    | серый | офлайн | нет баз или MCP остановлен пользователем | «Bilem Agent — офлайн…» |

    Двойной щелчок — окно; меню: «Открыть», «Скопировать адрес MCP», «Выход».
  </Step>
  <Step title="Ярлыки и трей">
    Ярлыки на рабочем столе и в «Пуске» + `bilem-agent shortcut`; крестик → трей с разовым уведомлением; выход — из меню трея; повторный запуск → то же окно.
  </Step>
  <Step title="Версия и вкладка MCP">
    Внизу справа — «Версия 0.1.0»; вкладка «Подключение» → «MCP».
  </Step>
</Steps>
