## Пачка 1 — 18.10.2026

<Steps>
  <Step title="Иконки — уже в репо">
    В `assets/icons/` (коммит Славы через веб, сделай `git pull`):

    - `bilem-agent.ico` — иконка приложения (16–256 px): exe (`ApplicationIcon`), окно, ярлыки, панель задач. **Всегда зелёная, не меняется.**
    - `tray-green.ico`, `tray-yellow.ico`, `tray-red.ico`, `tray-grey.ico` — **только для значка в трее** (16–64 px): тот же знак, перекрашенный целиком — на 16 px читается лучше, чем маленькая точка;
    - `app-512.png` — для README и сайта.

    Знак — фирменный знак Bilem (зелёный круг `#1FAF5A`, белое облачко). Иконки — встроенными ресурсами exe, не отдельными файлами рядом.
  </Step>
  <Step title="Статус в трее — цветной круг, без мигания">
    | Цвет | Смысл (формулировка Славы) | Когда именно | Подсказка при наведении |
    | --- | --- | --- | --- |
    | зелёный | работает хорошо | MCP слушает, все базы проходят проверку | «Bilem Agent — работает · баз: N» |
    | жёлтый | подключение, «застряла» | запуск, настройка базы, проверка; **если дольше 60 с — переходит в красный** с причиной «долго нет ответа» | «Bilem Agent — подключение…» |
    | красный | ошибка, что-то не завелось | MCP не смог запуститься (порт занят и т. п.) или хотя бы одна база с ошибкой | «Bilem Agent — ошибка: …» (коротко что) |
    | серый | офлайн | нет подключённых баз **или** MCP остановлен пользователем | «Bilem Agent — офлайн: базы не подключены» / «MCP остановлен» |

    Смена значка — только при смене состояния, никакой анимации. Двойной щелчок — открыть окно; меню по правой кнопке: «Открыть», «Скопировать адрес MCP», «Выход».
  </Step>
  <Step title="Не терять окно и ярлыки">
    Слава закрыл окно и не нашёл, как его открыть:

    - при первом запуске окна — ярлык **«Bilem Agent» на рабочем столе** и в **меню «Пуск»** (для всех пользователей — права администратора уже есть), с иконкой приложения; + CLI `bilem-agent shortcut` (создать/пересоздать);
    - крестик окна — свернуть в трей, MCP работает дальше; **один раз** показать уведомление «Bilem Agent работает в трее — значок справа внизу (может быть под стрелкой ˄)»; завершение — только через «Выход» в меню трея;
    - повторный запуск exe, когда агент уже работает, — не второй экземпляр, а показ уже работающего окна.
  </Step>
  <Step title="Версия в строке состояния">
    В строке состояния внизу — **«Версия 0.1.0»** (из версии сборки, не вручную). Порт остаётся слева: «MCP работает · порт 8796 · баз: 2», версия — справа.
  </Step>
  <Step title="Вкладка «Подключение» → «MCP»">
    Переименовать вкладку в **«MCP»** — там всё про MCP (адрес, токен, подключение к клиентам, облако). В строках ресурсов и доках — тоже.
  </Step>
</Steps>

## Приёмка пачки 1

- Ярлык на рабочем столе и в «Пуске» с зелёной иконкой; крестик → трей, двойной щелчок → окно; второй запуск → то же окно.
- Все четыре цвета трея показаны живьём: нет баз → серый; остановить MCP → серый; занять порт / сломать базу → красный; настройка базы → жёлтый; всё в порядке → зелёный. Снимки — в журнал.
- В строке состояния — версия; вкладка называется «MCP».
- Коммиты по правилам репо, хеши — в журнал v0.1.
