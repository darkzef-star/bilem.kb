## Пачка 4 — 18.10.2026 · компактное окно

Слава: при открытии окно слишком широкое, почти пол-экрана — для утилиты это лишнее; растягивать можно, но **по умолчанию — компактно**. Снизу вкладки «MCP» сейчас много пустого места.

<Steps>
  <Step title="Размер по умолчанию">
    Стартовый размер — около **640 × 440** логических пикселей (при 100 %; с PerMonitorV2 из пачки 2 масштабируется сам), по центру экрана. Минимальный размер — около **560 × 380**, меньше не сжимается. Растягивать и разворачивать — можно.
  </Step>
  <Step title="Вёрстка под узкое окно">
    Кнопки не должны обрезаться при минимальной ширине — раскладка потоком (`FlowLayoutPanel` / `TableLayoutPanel`), а не фиксированными координатами. На вкладке «MCP» кнопки — в две строки: «Подключить к Claude Code · Claude Desktop · Cursor» и «Сменить токен · Остановить MCP». Длинные пояснения переносятся по словам. Проверить все вкладки на минимальном размере и на 125 % / 150 %.
  </Step>
  <Step title="Запоминать, как оставил пользователь">
    Если пользователь сам изменил размер или положение — запомнить и в следующий раз открыть так же (настройка пользователя, не `config.json`). Окно, оказавшееся за пределами экранов (сменили монитор), — вернуть на основной экран. Сброс — к размеру по умолчанию.
  </Step>
</Steps>

## Пачка 3 — 18.10.2026 · вкладка «Сервис»

Порядок вкладок: **Базы 1С · MCP · Доступ к данным · Журнал · Сервис · О программе** («Сервис» — предпоследняя).

<Steps>
  <Step title="Что уходит из «Журнала»">
    С вкладки «Журнал» **переносятся** на «Сервис» кнопки «Диагностика компонентов» и «Собрать отчёт для поддержки». На «Журнале» остаются сам журнал и «Открыть папку журналов».
  </Step>
  <Step title="Состав вкладки «Сервис»">
    Группами, сверху вниз:

    **Проверка и поддержка**

    - **«Диагностика компонентов»** — как сейчас (`bilem-agent doctor`).
    - **«Собрать системную информацию»** — новая: краткая сводка для техподдержки, **сразу в буфер обмена** + «Сохранить в файл…». Состав: версия агента; Windows (версия, разрядность); .NET Framework; платформы 1С и разрядность; COM-коннектор; IIS и компоненты; порт и состояние MCP; по каждой базе — короткое имя, тип (файловая/серверная), **конфигурация и её версия**, есть ли БСП, число объектов OData, роли `bilem`, последняя проверка. **Без** паролей, токенов, путей к профилям пользователей и данных из 1С. CLI: `bilem-agent sysinfo`.
    - **«Собрать отчёт для поддержки»** — как сейчас (zip: журналы + системная информация + диагностика, без паролей и токенов).
    - **«Сообщить о проблеме на GitHub»** — ссылка на `https://github.com/skp-kz/bilem.agent/issues/new`; подсказка рядом: «приложите системную информацию — она уже в буфере обмена после кнопки выше».
    - Серым мелким текстом: **«Платная техподдержка появится в коммерческой версии. Сейчас — только через GitHub Issues.»**

    **Обновления** (заготовка, пока не работает)

    - Строка «Установлена версия 0.1.0».
    - Кнопка **«Проверить обновления»** — неактивная, рядом серым: «Скоро: обновление в один щелчок». Логику не делать — только место и разметка.
  </Step>
  <Step title="Тексты">
    Все строки — в `Strings.resx`; кнопки — глагол + что делаем, без жаргона.
  </Step>
</Steps>

<Note>
  Репо `bilem.agent` пока закрытый — ссылка на Issues для посторонних откроется после того, как репо станет публичным. Ссылку не прячем: к первому публичному релизу она заработает.
</Note>

## Пачка 2 — 18.10.2026

<Steps>
  <Step title="Иконка на панели задач мутная — чёткость и DPI">
    Слава: в трее иконка хорошая, а на панели задач — «пиксельная, плохо отрисована».

    - **Новый `assets/icons/bilem-agent.ico`** (коммит Славы через веб, `git pull`): размеры 16, 20, 24, 30, 32, 36, 40, 48, 60, 64, 72, 80, 96, 128, 256 — под любой масштаб экрана (100–250 %), чтобы Windows брала готовый размер, а не растягивала соседний.
    - **Включить DPI-осведомлённость**, иначе Windows растягивает всё окно битмапом и иконка мылится: в манифесте `<dpiAwareness>PerMonitorV2</dpiAwareness>` (+ `<dpiAware>true/pm</dpiAware>` для старых систем), в `app.config` — `System.Windows.Forms.ApplicationConfigurationSection` → `DpiAwareness = PerMonitorV2`; проверить, что вёрстка окон не поехала на 125 % и 150 %.
    - Иконку формы грузить из ресурса **целиком** (`new Icon(stream)`), не через `Icon.ExtractAssociatedIcon` (он отдаёт только 32 px) и не одним размером.
  </Step>
  <Step title="Иконка во всех окнах, не только в главном">
    Скриншот Славы: окно «Добавить базу 1С» — со стандартной иконкой Windows. **Все** окна и диалоги — с иконкой приложения. Общий базовый класс формы, который ставит `Icon` из ресурса; тест — что у каждой формы `Icon` не стандартный.
  </Step>
  <Step title="Пробел в $filter — %20, не +">
    Из разбора конкурента ([Конкуренты](/product/konkurenty)): 1С не декодирует `+` как пробел внутри `$filter` и отвечает 400. Проверить `find_counterparty` с фразой из нескольких слов; строка запроса — `Uri.EscapeDataString`. Тест + строка в known-issues.
  </Step>
  <Step title="Лимиты выборок">
    Размер страницы и защитный максимум строк на любой инструмент (по умолчанию 200 строк в ответе); если обрезали — пометка «показаны первые N из M, уточните запрос».
  </Step>
</Steps>

## Пачка 1 — 18.10.2026

<Steps>
  <Step title="Иконки — уже в репо">
    В `assets/icons/`: `bilem-agent.ico` — иконка приложения (exe, окна, ярлыки, панель задач), **всегда зелёная**; `tray-green/yellow/red/grey.ico` — **только для трея**; `app-512.png` — для README и сайта. Иконки — встроенными ресурсами exe.
  </Step>
  <Step title="Статус в трее — цветной круг, без мигания">
    | Цвет | Смысл | Когда именно | Подсказка |
    | --- | --- | --- | --- |
    | зелёный | работает хорошо | MCP слушает, все базы проходят проверку | «Bilem Agent — работает · баз: N» |
    | жёлтый | подключение, «застряла» | запуск, настройка, проверка; **дольше 60 с → красный** с причиной «долго нет ответа» | «Bilem Agent — подключение…» |
    | красный | ошибка | MCP не запустился или база с ошибкой | «Bilem Agent — ошибка: …» |
    | серый | офлайн | нет баз **или** MCP остановлен пользователем | «Bilem Agent — офлайн…» |

    Смена значка — только при смене состояния. Двойной щелчок — окно; меню: «Открыть», «Скопировать адрес MCP», «Выход».
  </Step>
  <Step title="Не терять окно и ярлыки">
    Ярлык «Bilem Agent» на рабочем столе и в «Пуске» (для всех пользователей) + `bilem-agent shortcut`; крестик → трей с разовым уведомлением; выход — только из меню трея; повторный запуск → то же окно.
  </Step>
  <Step title="Версия в строке состояния">
    Внизу справа — «Версия 0.1.0» (из сборки); слева — «MCP работает · порт 8796 · баз: 2».
  </Step>
  <Step title="Вкладка «Подключение» → «MCP»">
    В ресурсах и доках тоже.
  </Step>
</Steps>

## Приёмка

- Пачка 1: ярлыки с зелёной иконкой; крестик → трей, двойной щелчок → окно; второй запуск → то же окно; четыре цвета трея живьём (снимки в журнал); версия в строке состояния; вкладка «MCP».
- Пачка 2: иконка на панели задач чёткая на 100 %, 125 %, 150 % (снимки); у всех окон и диалогов — иконка приложения; поиск по фразе с пробелом работает; длинная выборка обрезается с пометкой.
- Пачка 3: порядок вкладок как выше; на «Журнале» — только журнал и папка; на «Сервисе» — диагностика, системная информация (в буфере, без секретов — показать текст в журнале), отчёт, ссылка на Issues, серая строка про платную поддержку, неактивная «Проверить обновления»; снимок вкладки — в журнал.
- Пачка 4: первое открытие — компактное окно по центру; на минимальном размере ни одна кнопка не обрезана (снимки всех вкладок); изменённый размер запоминается.
- Коммиты по правилам репо, хеши — в журнал v0.1.
