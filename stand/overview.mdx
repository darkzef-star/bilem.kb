Сервер `BAKANOF`, Windows Server 2025, база `lakomka` (демо БП для КЗ, ТОО «ТД Лакомка»). Это рабочее место Баканова: что докручивать — решает он.

## Что стоит

| Инструмент | Зачем |
|---|---|
| Git, GitHub Desktop, `gh` | репо `bilem.cfe`, PR и issues из терминала |
| Node.js 24, Claude Code | терминальный агент, вход под своим Max |
| Windows Terminal, PowerShell 7 | в старой консоли Claude Code ломает кириллицу |
| VS Code + Language 1C (BSL) | диффы выгрузки `src/` |
| jq, Bruno | читать JSON, коллекция запросов |
| cloudflared (`bakanov-stand`) | RDP снаружи — `rdp.bilem.dev` |
| Tailscale, TeamViewer | доступ Славы |
| Effector Saver | бэкапы баз 1С на Synology |

## Бэкапы

Synology Active Backup: мастер-образ после установки + еженедельная задача `weekly`. Effector Saver — базы 1С.

<Warning>
  Не трогать: политику обоев и Shadow, службы `Cloudflared`, `Tailscale`, `MixbackupService`, `TeamViewer`, сетевой профиль Private и правила RDP.
</Warning>
