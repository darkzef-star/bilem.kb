### Решения

- **MCP — своя реализация**, не официальный C# SDK: SDK рассчитан на .NET 8+ и ASP.NET Core, на net48 не встаёт. Реализовано по спецификации: `initialize` (версии 2025-06-18 / 2025-03-26 / 2024-11-05), `notifications/*` → 202, `ping`, `tools/list`, `tools/call`; ответы — `application/json`, без сессий.
- **HTTP — на TcpListener(127.0.0.1)**, не HttpListener: http.sys по умолчанию слушает все адреса машины и проверяет только заголовок Host. С другого адреса соединение не устанавливается вовсе (юнит-тест + проверка на стенде).
- **CLI и окно — один exe с консольной подсистемой**: у команд нормальные вывод и код возврата; при запуске двойным щелчком консоль прячется.
- **Помощник COM — `dynamic` C#**: свойства объектов 1С видны (в PowerShell — нет); коллекции — через `Count()/Get(i)` и `Contains`, без перечисления.
- **Порт MCP по умолчанию — 8796** (8795 занят Node-прототипом на стенде).
- **JSON — Newtonsoft.Json 13.0.4** (единственный внешний пакет в программе). Пакеты — версии старше двух недель.
- **Тексты** — один файл `Resources/Strings.resx` (267 строк); тест проверяет, что все ключи из кода есть.

### Вопросы Славе

1. **Право `workflow` у токена GitHub на стенде.** GitHub не принимает `.github/workflows/build.yml` от OAuth-токена без этого права. Нужно один раз на стенде: `gh auth refresh -h github.com -s workflow` (откроет код для браузера) — после этого запушу CI. Или добавь файл через веб-интерфейс GitHub — пришлю текст.
2. **Ссылка «лист ожидания».** Сейчас в окне ведёт на bilem.ai — дай точный адрес, если есть отдельная страница.
3. **Имя MCP в Claude Code — `bilem`** (уровень пользователя Windows). В папке репо bilem.cfe есть свой `bilem` (старый MCP cfe) — там он перекроет агента. Переименовать в `bilem-agent`?
4. **.NET Framework 4.8 на 2008 R2 / 2012 R2** не стоит из коробки — в v0.1 только сообщение в README; нужен ли проверочный шаг в программе? **Ответ Славы (18.10.2026): да — и предложение скачать после установки MSI, перед первым запуском.** Сейчас (zip v0.1): в `bilem-agent.exe.config` — `supportedRuntime sku=".NETFramework,Version=v4.8"`, без 4.8 Windows сама показывает системное окно «нужен .NET Framework 4.8 — скачать?». В MSI (v0.2): проверка `HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full`, `Release ≥ 528040`; если ниже — после установки, до первого запуска, наше окно по-русски со ссылкой на загрузку 4.8 (для 2008 R2 — напоминание про SP1, возможная перезагрузка).
