## 18.10.2026 · шаги 1–4 (диагностика), жду «ок» на Apply

**Стенд:** PowerShell от администратора — True. Платформа 8.3.27.2342, **только 32-бит** (64-битной нет). Копия эталона — 0,4 с (1,3 ГБ). Эталон не открывался.

### Прогоны

| --- | --- | --- | --- | --- |
| v1 | диагностика | шаг 2, бесконечный перезапуск | В 32-битном PowerShell переменная ProgramFiles указывает на «Program Files (x86)» — 32-битная 1С принималась за 64-битную, скрипт перезапускался 64↔32 раз в секунду (624 журнала, остановлен вручную) | 64-битная папка берётся из ProgramW6432; повторный перезапуск запрещён — ошибка вместо петли; appcmd и iprestr.dll из 32-битного процесса — через Sysnative |

| v3 | диагностика | — | Прошла, код 0, 1,4 с | — |

### Диагностика v3

- Платформа 8.3.27.2342 (32-бит), скрипт перезапускается в 32-битном PowerShell.
- План: зарегистрировать comcntr.dll (TypeLib), затем вход по COM.
- **Конфигурация, версия, БСП — пока не видны:** без регистрации COM в базу не войти, а регистрация меняет машину — только под Apply. Появятся в первом прогоне с Apply.

### Решения для Славы перед Apply

1. **Ограничение по IP.** Компонента IIS «Ограничения по IP» на стенде нет. Без флага EnableIIS публикация будет открыта не только с 127.0.0.1, проверка «по IP стенда — 403» не пройдёт. С EnableIIS скрипт поставит компонент Windows Web-IP-Security (рабочие публикации и пулы не трогает). Запускать с EnableIIS?
2. **Регистрация comcntr.dll** — regsvr32 перерегистрирует COM-коннектор платформы 8.3.27.2342 для всей машины (публикации и базы не затрагивает).

Следующий прогон — v4 с Apply. Копии v1, v2 не тронуты (скрипт до базы не дошёл).

### Изменения скрипта (+29 / −11)

- Шаг 2: корни Program Files по реальной разрядности ОС (ProgramW6432 и ProgramFiles(x86)), а не процесса.
- Перезапуск в PowerShell нужной разрядности: флаг-переменная окружения, второй перезапуск — ошибка с подсказкой.
- COM-коннектор: функция проверки ProgID, пути dll и TypeLib; после regsvr32 — повторная проверка.
- Шаги 8–9: путь к appcmd и iprestr.dll через Sysnative, если процесс 32-битный.

Исправленный скрипт — на стенде, на прежнем месте; исходник и полный diff — у Земли.
