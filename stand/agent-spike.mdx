## Заход 3 — потом: узкие права bilem

Зачем: «Полные права» позволяют `bilem` читать, создавать, проводить и удалять что угодно. Периметр и MCP — это «дверь»; узкие роли — «сейф» внутри 1С: даже если MCP по ошибке попросит удалить или провести, 1С ответит «нет прав». Клиенту: «у нашего пользователя в вашей 1С — только чтение».

Что проверить:

- роли из кандидатов (журнал спайка, вывод `-ListRoles`) вместо «Полных прав» — OData по составу читается;
- **запись запрещена**: попытка создать документ через OData — отказ 1С;
- **БСП не сбрасывает роли**: после входа администратора и регламентных заданий роли у `bilem` на месте. Сбрасывает — переходим на профиль групп доступа «Bilem».

Старт — по команде Славы.
