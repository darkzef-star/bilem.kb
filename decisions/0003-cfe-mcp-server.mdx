## Решение

MCP по Streamable HTTP — это `POST` JSON-RPC 2.0 на один адрес. HTTP-сервис 1С это умеет. Публикация базы на IIS даёт сразу и REST, и MCP:

```
POST /hs/bilem/mcp/<токен>
```

## Почему

- Ноль промежуточного кода: клиент (Claude, Cursor, OpenClaw) подключается прямо к 1С.
- Новый метод в cfe автоматически появляется в `tools/list` — каталог строится из установленной версии расширения.
- Токен в пути — для клиентов без заголовков (ChatGPT, коннекторы Claude Desktop); `Authorization: Bearer` тоже принимается.

## Что из этого следует

- Служба Windows и облачный ретранслятор — надстройки, не обязательны.
- Порядок у Баканова: `GET /org` → MCP с одним инструментом `org` → подключение к Claude Code на стенде → дальше методы по одному.
- Обработка «Подключение Bilem» в cfe: кнопка «Сгенерировать токен» и готовые сниппеты подключения.
- Детали — [Контракт cfe](/cfe/spec).
