## Решение

- **Azure Artifact Signing на SKP.kz LLC** (техасская LLC, ~7 месяцев). Издатель в Windows — «SKP.kz LLC». Подпись — **автоматически в GitHub Actions** на каждом релизе (официальный шаг Microsoft), без ручного шага на стенде. Тариф Basic, по сторонним данным ~\$9.99/мес (точная цена — при выборе тарифа).
- **Домен проверки — `bilem.ai`** (Cloudflare Registrar): владелец в контактах регистратора — «SKP.kz LLC»; Website `https://bilem.ai`; почта `slava@bilem.ai` + `admin@bilem.ai` (Cloudflare Email Routing → почта Славы). `skp.kz` не берём: .kz регистрируется на физлицо / казахстанское ТОО, не совпадёт с LLC.
- **Первая бета (v0.3.0) — без подписи.** Целостность обновлений — своей подписью релиза (Ed25519, открытый ключ зашит в агент). Когда Microsoft выдаст сертификат — следующий релиз подписан, агент дополнительно проверяет издателя «SKP.kz LLC».
- **D-U-N-S** не нужен для Azure. Нужен для Apple Developer (\$99/год) — позже.

## Что нужно от Славы (по quickstart Microsoft, май 2026)

1. Cloudflare: bilem.ai → Registrar → Contacts → Organization «SKP.kz LLC», адрес как в документах LLC; Email Routing: `slava@bilem.ai`, `admin@bilem.ai`.
2. portal.azure.com: подписка; Resource providers → `Microsoft.CodeSigning` → Register.
3. Artifact Signing Account (East US / Central US, Basic); себе роль **Artifact Signing Identity Verifier**.
4. Identity validation → Organization → Public: название точно как в свидетельстве штата Техас; Website `https://bilem.ai`; два e-mail на bilem.ai; Business Identifier — Texas SOS File Number или EIN; адрес LLC; имя и фамилия — как в паспорте. Потом — проверка личности по ссылке (паспорт + селфи).
5. Ждать «Completed» (1–20 рабочих дней). Документы — выданные не раньше 12 месяцев назад (свидетельство штата подходит); могут попросить документ о домене — счёт Cloudflare с LLC.
6. Certificate profile **Public Trust**. Затем — приложение в Entra ID для GitHub (OIDC) с ролью подписи; в секреты репо — tenant / client / subscription ID (идентификаторы, не пароли). Пошагово — когда дойдём.

## Почему передумали

- Своё имя издателя и полностью автоматическая подпись без ручных шагов — за ~\$120/год.
- Появилась американская LLC — Azure стал доступен (Public Trust — для организаций США, Канады, ЕС, UK и др.); требования «3 года работы» в текущей инструкции нет.
- SignPath требует открытой сборки, репутации проекта и ставит своё имя — новому проекту без звёзд могут отказать.

## Запасной план

- **Certum Standard Code Signing in the Cloud** (SimplySign) на LLC, от €49 на ~15 месяцев; проверка 1–5 рабочих дней, звонок — на телефон из независимого справочника (D&B); подпись — вручную на стенде.
- **SignPath Foundation** — бесплатно, если откроем код и наберём репутацию.

## Что отвергли

- **EV** — дороже, мгновенного доверия SmartScreen больше не даёт.
- **USB-токен** — ключ привязан к одной машине.

Мгновенного доверия SmartScreen не даёт ни один вариант: репутация издателя копится по мере скачиваний. Подробности — `docs/ideas/code-signing.md` в minidesk.
