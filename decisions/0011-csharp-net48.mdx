## Решение

Bilem Agent пишем на **C#, .NET Framework 4.8, WinForms** (классическое окно Windows, вариант A). Минимальная Windows — Server 2008 R2 SP1. Работаем сами (Земля + Cowork), не дожидаясь Станислава.

## Почему

- Всё на Windows-специфике: COM к 1С (пользователь `bilem`, состав OData, роли), WinForms, служба, DPAPI, IIS — у C# всё родное.
- У Go для 2008 R2 / 2012 R2 — только Go 1.20 без патчей безопасности; GUI (lxn/walk) не развивается; COM через go-ole громоздко; Go-бинарники чаще ловят ложные срабатывания антивирусов.
- .NET 4.8 есть из коробки на Server 2016+ / Windows 10; exe — сотни КБ. Собирается `dotnet build` где угодно, в том числе в GitHub Actions.

## Что отвергли / отложили

- Go 1.20 + lxn/walk — см. выше.
- .NET 8 — не на старых серверах и тянет рантайм.

## Что из этого следует

- Известный минус: TLS 1.2 на 2008 R2 / 2012 R2 — из системы; для облачного режима агент проверяет и подсказывает, как включить.
- MCP: официальный C# SDK — если встаёт на net48; иначе своя реализация (JSON-RPC по HTTP, протокол небольшой).
- ТЗ первой версии — [Bilem Agent v0.1](/stand/agent-app-v01).
