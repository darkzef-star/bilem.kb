## Решение

- **Локальный Bilem Agent — бесплатный, с открытым кодом (open core), без лимита баз.** Сколько баз пользователь сам укажет — столько MCP и объявит (у каждой базы короткое имя, инструменты принимают параметр «база»).
- **Платное — то, что физически на нашей стороне:** облачный `mcp.bilem.ai` с OAuth (ChatGPT, claude.ai, голос, телефон), каналы WhatsApp/Telegram, поддержка. Там и лимиты, и тарифы.
- Код открываем, чтобы его могли проверить безопасники клиента: что программа делает с данными и куда их отправляет.

## Почему

- Лимит в открытом коде не удержать: любой рукастый (или его Claude Code) снимет его за минуту. Ограничивать имеет смысл только серверную сторону.
- Люди ленивые и берут готовое: «скачал — работает — уже подключено к моему ИИ». Сами так выбрали базу знаний — нашли готовую, с MCP, бесплатно.
- Открытый бесплатный инструмент можно **советовать**, не нарушая правил площадок: реклама банится, а «вот бесплатная штука, решает вашу задачу» — помощь. Звёзды на GitHub, обсуждения, рекомендации ИИ.
- Кому нужно облако, голос, ChatGPT и поддержка — придут и заплатят: в README и программе ссылки на bilem.ai и лист ожидания.

## Что отвергли / отложили

- Лимит баз в бесплатной версии (Developer 1, Standard 2, Pro до 5) — для локального агента снимаем; лимиты — только у облачных тарифов.
- Закрытый код с подписью — подпись нужна всё равно (кто выпустил), но вместо открытого кода не годится: на вопрос «что программа делает с моими данными» отвечает только открытый код.

## Что из этого следует

- Поправить тарифы (`bilem-dev/pricing.json` → сайт и кабинет): у локальной версии «без лимита баз», лимиты баз и людей — у облачных тарифов. Делаем отдельно, по команде Славы.
- Карточка Free на странице [Open core и тарифы](/product/open-core) — теперь Bilem Agent вместо cfe.
- Отдельная задача — [ИИ-находимость](/product/ai-nakhodimost): чтобы ChatGPT, Claude и поиск сами находили и советовали Bilem.
- Арман (маркетинг): поиск обсуждений, где наш бесплатный инструмент решает задачу, — советовать, а не рекламировать.
