## Решение

| Что | Где |
|---|---|
| Задачи | GitHub Issues в репо, где живёт код; все — на [доске bilem.ai](https://github.com/orgs/skp-kz/projects/3) |
| Код cfe | [skp-kz/bilem.cfe](https://github.com/skp-kz/bilem.cfe) |
| Знания, решения, встречи | эта база — репо `skp-kz/bilem.kb`, сайт на Mintlify |

Старые ТЗ в `bilem.cfe/docs/requests/` — архив, новые не пишем.

## Почему

- Claude Code Баканова уже работает с GitHub (`gh`, GitHub MCP) — никаких новых ключей.
- PR закрывает issue сам (`Closes #N`), карточка на доске уезжает в Done.
- База — markdown в git: история, откат, бэкап. Сайт поверх — читать приятно людям.
- Mintlify бесплатно даёт приватный сайт, поиск и MCP для агентов.

## Что из этого следует

- Канбан bilem.dev остаётся для бизнеса (клиенты, Brain, Диалоги), разработку туда не пишем.
- В `bilem.cfe/CLAUDE.md` — правило: начинать сессию с `gh issue list --assignee @me`.
