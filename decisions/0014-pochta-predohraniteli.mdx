**Дата:** 18.10.2026 · **Кто:** Слава · **Статус:** принято, детали — в ТЗ v0.3 «Почта» (продолжим 18.10)

Принцип: **модель не решает, кому и что отправить — она предлагает; решают настройки и человек.** Почтовый ящик клиента любой (SMTP + пароль приложения), свой на каждую базу; пароль — зашифрован для этой машины (DPAPI), кнопка «Проверить» — тестовое письмо себе.

## Берём (бесплатно, по умолчанию)

| Предохранитель | Как |
| --- | --- |
| **Подтверждение человеком с превью PDF** | перед отправкой агент **показывает сам PDF**, адресата и текст письма; отправляет кнопка «Отправить» мимо модели (так же записать в наш скилл) |
| **Адресаты счёта и акта сверки — любые** (изменено 18.10) | по умолчанию — e-mail контрагента из 1С; пользователь может назвать любой другой адрес. Секретного в этих документах нет, ответственность — на подтверждающем; защита — подтверждение с превью, журнал, скрытая копия, лимиты |
| **Доверенность — только своим** | в настройках базы — список адресов для доверенностей (главбух, директор); доверенность уходит **только туда**, дальше пересылает человек; подтверждение не отключается |
| **Скрытая копия себе** | каждое письмо — копией на ящик компании (аудит) |
| **Лимиты** | напр. 10 писем в час и 50 в день на базу (настраиваемо) |
| **Только наши документы** | вложение — только PDF, сделанный агентом (счёт, доверенность, акт сверки); текст — шаблон + короткая приписка, видна при подтверждении; один адресат |
| **Журнал и рубильник** | кому / какой документ / когда / кто подтвердил (без содержимого); «Почта выключена» — в один щелчок (окно и трей) |

## Не берём

- **Белый список доменов для всех писем** — у клиента десятки контрагентов, заносить каждого неудобно («не Сбербанк»). Достаточно адресатов из 1С + подтверждения. Исключение — список адресов для доверенностей.

## Облако (платно)

- Подтверждение **с телефона** (WhatsApp / Telegram) — в бесплатной кнопка есть только на машине с агентом.
- Права по людям: кто готовит, кто отправляет; цепочка одобрений (менеджер → директор); политики адресатов; выгрузка журнала. На вкладке «Почта» — серый блок с меткой «Облако».

## Открыто

- **PDF в чат:** Земля не смогла прислать PDF в чат (Claude Code / Remote Control). Разобраться: отдавать из `print_invoice` превью (PNG первой страницы как image content MCP) + путь/ссылка на файл; проверить в Claude Desktop, Claude Code, ChatGPT.
