## Решение

- Открытый код — только `bilem.cfe` (REST + MCP в одном расширении).
- Облачный ретранслятор `mcp.bilem.ai` и служба bilem-agent — закрытые, в коммерческой лицензии, необязательные: делают то же, что локальный MCP, но без публикации руками.
- Отдельный репо «облачный MCP» не выкладываем.
- MCP не закрываем и не продаём отдельно — платят за подписку по БИН.

## Почему

cfe повторяется за неделю — прятать нечего. Открытый исходник даёт доверие: 1С-ник клиента сам проверит, что расширение ничего не проводит. Деньги — с тех, кому нужен сервис, канал, Enterprise.

## Что из этого следует

- Free-путь: cfe + локальный MCP → Claude Desktop клиента, без нашего облака и токенов.
- Продвижение — только после живого демо и первых клиентов.
- См. [Open core и тарифы](/product/open-core).
