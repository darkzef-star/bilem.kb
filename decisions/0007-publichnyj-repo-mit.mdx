## Решение

- Репо `skp-kz/bilem.cfe` становится **публичным** — следствие [0001 · open core](/decisions/0001-open-core).
- Лицензия — **MIT**.
- Дистрибуция — **GitHub Releases**: релиз = тег `vX.Y.Z` + `bilem.cfe` + `bilem.cfe.sha256` + описание изменений. Зеркало на bilem.ai — позже, когда станет много клиентов.

## Почему MIT, а не AGPL

| | MIT | AGPL-3.0 |
| --- | --- | --- |
| Франчайзи 1С | свободно встраивает и продаёт | обязан открыть доработки |
| Юристы клиентов | не возражают | часто запрещают |
| Защита от копирования | нет | сильная |

cfe — вход в воронку: чем больше 1С-ников её поставят, тем больше клиентов. Деньги — в службе, облаке, канале и поддержке, они закрытые. Копию cfe сделать можно за неделю при любой лицензии — защищать нечего, распространение важнее.

## Как работает обновление

<Steps>
  <Step title="Релиз">
    Земля собирает `.cfe` на стенде (GitHub Actions собрать не может — нужна платформа 1С) и выпускает: `gh release create v0.10.0 bilem.cfe bilem.cfe.sha256 --notes-file CHANGELOG.md`. Версия в теге = `Метаданные.Версия` расширения.
  </Step>
  <Step title="Проверка">
    cfe при входе администратора читает `https://api.github.com/repos/skp-kz/bilem.cfe/releases/latest`, сравнивает `tag_name` со своей версией, показывает «Доступна» и «Что нового» (текст релиза).
  </Step>
  <Step title="Установка">
    По кнопке администратора: скачать `bilem.cfe`, сверить SHA-256, записать через `РасширенияКонфигурации`, применить при следующем входе. Ставит только администратор с правом администрирования расширений — не пользователь `bilem` ([0006](/decisions/0006-prava-v-1c)). «Обновлять автоматически» = предлагать при входе администратора, не ставить молча.
  </Step>
</Steps>

## Перед публикацией — чек-лист

- [x] Внутренние доки перенесены в базу: спека, каталог, стенд, первый день, [журнал](/process/zhurnal-cfe), [ТЗ 0000/0001](/cfe/tz-0000-0001)
- [ ] Выгрузка расширения в `src/` закоммичена (сейчас там только `.gitkeep`)
- [ ] Новый **публичный репо с чистой историей**: первый коммит — `src/`, `README.md`, `LICENSE`, `CHANGELOG.md`; текущий репо остаётся приватным архивом (в его истории — адреса стенда, почты, внутренняя переписка)
- [ ] В публичный репо **не попадает**: документация ИТС (запрещено лицензией), `CLAUDE.md` с внутренними деталями, `.mcp.json` со стендом, токены
- [ ] `LICENSE` — MIT, правообладатель ТОО «СКП»
- [ ] Публичный README: что это, граница «не трогаем учёт», установка, подключение MCP, ссылка на bilem.ai, «поддержка — только при коммерческом использовании»
- [ ] Первый релиз `v0.1.0`; вкладка «Обновления» читает «Доступна» с GitHub по-настоящему

<Note>
  Работа Земли и Воздуха (задачи, решения, журнал) после публикации остаётся в закрытых местах: эта база и приватная доска. В публичном репо — только код и публичная документация.
</Note>
