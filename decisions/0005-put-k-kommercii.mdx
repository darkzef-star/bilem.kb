## Решение

| | cfe (бесплатно, локально) | Bilem (платно) |
|---|---|---|
| Канал к 1С | клиент публикует сам, туннель сам | служба `bilem-agent` на Go |
| Авторизация MCP | токен в пути или Bearer | OAuth 2.1 через **Auth0** — тот же тенант, что кабинет `app.bilem.ai` |
| Клиенты | Claude Desktop/Code, Cursor, OpenClaw | + ChatGPT, claude.ai, телефон |

## Почему

- ChatGPT и коннекторы claude.ai подключают только удалённый MCP с OAuth — это и есть ценность платной версии.
- Auth0 даёт `/authorize`, `/token`, Dynamic Client Registration без своего кода. Наш Worker проверяет JWT и сопоставляет пользователя с организацией.
- Один вход: директор зашёл в кабинет через Google — тем же Google подключил ChatGPT.

## Что из этого следует

- Порядок: cfe → тестовый канал → служба → `mcp.bilem.ai` → подпись кода. См. [Дорожная карта](/product/roadmap).
- Подпись кода (сертификат) — только когда устанавливать будут чужие. Первым своим (Зимину) ставим вручную.
- Служба на Go: без `garble`/UPX — антивирусы режут именно это.
