  <Tab title="0000 · Документация 1С">
    **От:** Воздух · **Кому:** Земля · **Приоритет:** вместе с 0001

    ### Зачем

    Claude знает язык 1С в общем, но не знает точных имён объектов БП для Казахстана 3.0 (документы, регистры, счета «Хозрасчётного» 1210/3310/3350/3100…), особенностей HTTP-сервисов и расширений, функций БСП для печати и почты. Без этого он угадывает имена и ошибается.

    ### Что собрать (текстом, не PDF)

    1. **HTTP-сервисы платформы** — `HTTPСервисЗапрос` / `HTTPСервисОтвет`, шаблоны URL, публикация.
    2. **Расширения конфигурации** — что можно добавлять, ограничения, режим совместимости.
    3. **Объекты БП КЗ 3.0** — главное: документы, регистры, план счетов с кодами, справочники — имя в конфигураторе, ключевые реквизиты, типовой запрос остатка/оборота.
    4. **Печать и почта** — `УправлениеПечатью`, PDF через `ТабличныйДокумент.Записать`, учётная запись почты.
    5. **Налоговый календарь** — где в базе сроки форм 100.00/300.00/200.00/910.00.

    ### Где хранить

    <Warning>
      Лицензия ИТС запрещает публиковать документацию 1С. В публичный репо `bilem.cfe` она **не попадает**. Пересказ своими словами — в [раздел 1С этой базы](/onec/index) (база закрытая), полные тексты — локально на стенде.
    </Warning>

  <Tab title="0001 · GET /org + MCP-скелет">
    **От:** Воздух · **Кому:** Земля · **Приоритет:** первый

    ### Что нужно

    1. HTTP-сервис `bilem`, корень `/hs/bilem`.
    2. Константа `BilemТокен`, в форме «Подключение Bilem» — кнопка «Сгенерировать токен» (64 символа).
    3. `GET /org` — по [контракту](/cfe/spec).
    4. `GET /tools` — список из одного инструмента `org`.
    5. `GET /health` — версии и `as_of`.
    6. `POST /mcp/…` — `initialize`, `notifications/initialized`, `tools/list`, `tools/call` для `org`, `ping`.
    7. Роль `Bilem_Справочники` (см. [0006](/decisions/0006-prava-v-1c)); пользователь `bilem` только с ней. Без привилегированного режима.

    ### Приёмка (curl на стенде)

    ```bash
    curl -s -H "Authorization: Bearer $T" http://localhost/lakomka/hs/bilem/org
    curl -s -X POST http://localhost/lakomka/hs/bilem/mcp/$T -H 'content-type: application/json' \
      -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
    curl -s -X POST http://localhost/lakomka/hs/bilem/mcp/$T -H 'content-type: application/json' \
      -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"org","arguments":{}}}'
    ```

    Затем: `claude mcp add bilem http://localhost/lakomka/hs/bilem/mcp/$T` и вопрос «что за база?» — ответ из 1С.

    ### Результат

    Выгрузка в `src/`, PR из ветки `cfe/…-org`, запись в [Журнал cfe](/process/zhurnal-cfe).
