<Info>
  Первая живая цепочка: Claude вызывает инструмент `whoami`, отвечает 1С на стенде. Минимум кода, чтобы проверить всё сразу — HTTP-сервис, MCP, публикацию, туннель, коннектор. Дальше Баканов превращает это в `org` по [контракту](/cfe/spec). Код написан без запуска — первый синтаксический контроль на стенде.
</Info>

Всё на стенде, в сессии `vprimin`, Конфигуратор — **от имени администратора**. База уже опубликована как `/lakomka` (веб-клиент), снаружи `1c.bilem.dev` за Cloudflare Access.

## 1. Объекты в расширении `bilem`

| Объект | Имя | Настройки |
| --- | --- | --- |
| Константа | `BilemТокен` | Строка, 64 |
| HTTP-сервис | `bilem` | Корневой URL `bilem`, повторное использование сеансов — автоматически |
| └ шаблон | `whoami` | `/whoami`, GET → `whoamiGET` |
| └ шаблон | `mcp` | `/mcp/{token}`, POST → `mcpPOST`, GET → `mcpGET` |
| Роль | `Bilem_Агент` | HTTP-сервис `bilem` — Использование; Константа `BilemТокен` — Чтение |

Модуль HTTP-сервиса — целиком из раздела «Модуль» внизу страницы. Обработчики, которые Конфигуратор создаст сам, удалить. Затем **F7 — Обновить конфигурацию базы данных**.

## 2. Пользователь 1С `bilem`

- 1С → Администрирование → Пользователи → Создать: имя `bilem`, пароль (в чат не пишем), снять «Показывать в списке выбора», стандартный профиль только на чтение (строгие роли [0006](/decisions/0006-prava-v-1c) — позже).
- Конфигуратор → Администрирование → Пользователи → `bilem` → Прочие → роль **`Bilem_Агент`**.

## 3. Токен

PowerShell на стенде — 64 символа в буфер:

```powershell
$b = New-Object byte[] 32; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)
$T = -join ($b | % { $_.ToString('x2') }); Set-Clipboard $T; "длина: $($T.Length)"
```

1С → Сервис и настройки → Ещё → **Все функции** → Константы → `BilemТокен` → вставить → Записать. (Нет «Все функции» — Сервис и настройки → Параметры → «Отображать команду Все функции».) Окно PowerShell не закрывать.

## 4. Отдельная публикация для API

Администрирование → Публикация на веб-сервере: имя `lakomka-api`, каталог `C:\inetpub\wwwroot\lakomka-api\`. **Снять** клиентские приложения, OData, аналитику, Web-сервисы; **оставить** HTTP-сервисы и HTTP-сервисы расширений.

Блокнот от администратора → `C:\inetpub\wwwroot\lakomka-api\default.vrd`, в строке `ib="File=&quot;…1с база&quot;;"` дописать перед закрывающей кавычкой:

```text
Usr=bilem;Pwd=ПАРОЛЬ_BILEM;
```

`iisreset`. API работает от `bilem` без логина в запросе, веб-клиент в этой публикации не опубликован.

## 5. Проверка на стенде

```powershell
Invoke-RestMethod -Uri "http://localhost/lakomka-api/hs/bilem/whoami" -Headers @{Authorization="Bearer $T"} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri "http://localhost/lakomka-api/hs/bilem/mcp/$T" -ContentType "application/json" `
  -Body '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"whoami","arguments":{}}}' | ConvertTo-Json -Depth 6
```

Первая — JSON с `user: bilem`, конфигурацией, организацией. Вторая — то же внутри `result.content[0].text`.

## 6. Наружу

- Cloudflare Access: **Bypass** только для `1c.bilem.dev/lakomka-api/hs/bilem/mcp` (путь защищён токеном). Остальной `1c.bilem.dev` — за входом.
- Claude → Settings → Connectors → Add custom connector → `https://1c.bilem.dev/lakomka-api/hs/bilem/mcp/…токен` — токен вставляется в поле самому, не в чат.

## Если не работает

| Симптом | Причина |
| --- | --- |
| 404 на `/hs/bilem/…` | расширение не обновлено (F7) или нет галки «HTTP-сервисы расширений» в публикации |
| 401 от 1С (не наш JSON) | неверный `Usr/Pwd` в `default.vrd` или у `bilem` нет роли `Bilem_Агент` |
| `{"error":"unauthorized"}` | токен не совпал или константа пустая/короче 32 |
| 500 | ошибка в модуле — синтаксический контроль, журнал регистрации |

## Модуль

<Accordion title="Модуль HTTP-сервиса bilem — развернуть" icon="code">

```bsl
// HTTP-сервис bilem (расширение bilem) — минимальная проверка цепочки 1С → MCP.
// Шаблоны:  /whoami        GET  → whoamiGET   (проверка curl, токен в заголовке Authorization: Bearer)
//           /mcp/{token}   POST → mcpPOST     (MCP Streamable HTTP, JSON-RPC 2.0, без SSE)
//           /mcp/{token}   GET  → mcpGET      (405 — SSE не поддерживаем)
// Один инструмент: whoami. Ничего не пишет в базу. Привилегированный режим не используется.

#Область ОбработчикиШаблонов

Функция whoamiGET(Запрос)

	Если Не ТокенВерен(ТокенИзЗаголовка(Запрос)) Тогда
		Возврат ОтветJSON(401, ОшибкаПростая("unauthorized"));
	КонецЕсли;

	Возврат ОтветJSON(200, КтоЯ());

КонецФункции

Функция mcpGET(Запрос)

	Ответ = Новый HTTPСервисОтвет(405);
	Ответ.Заголовки.Вставить("Allow", "POST");
	Возврат Ответ;

КонецФункции

Функция mcpPOST(Запрос)

	Если Не ТокенВерен(Запрос.ПараметрыURL.Получить("token")) Тогда
		Возврат ОтветJSON(401, ОшибкаПростая("unauthorized"));
	КонецЕсли;

	Попытка
		Сообщение = ПрочитатьJSONИзСтроки(Запрос.ПолучитьТелоКакСтроку("UTF-8"));
	Исключение
		Возврат ОтветJSON(400, ОшибкаRPC(Неопределено, -32700, "Parse error"));
	КонецПопытки;

	Если ТипЗнч(Сообщение) <> Тип("Соответствие") Тогда
		Возврат ОтветJSON(400, ОшибкаRPC(Неопределено, -32600, "Invalid Request"));
	КонецЕсли;

	Ид = Сообщение.Получить("id");
	Метод = Строка(Сообщение.Получить("method"));
	Параметры = Сообщение.Получить("params");

	// Уведомление (без id), например notifications/initialized — ответа не требует.
	Если Ид = Неопределено Тогда
		Возврат Новый HTTPСервисОтвет(202);
	КонецЕсли;

	Если Метод = "initialize" Тогда
		Результат = Инициализация(Параметры);
	ИначеЕсли Метод = "ping" Тогда
		Результат = Новый Соответствие;
	ИначеЕсли Метод = "tools/list" Тогда
		Результат = СписокИнструментов();
	ИначеЕсли Метод = "tools/call" Тогда
		Результат = ВызовИнструмента(Параметры);
	Иначе
		Возврат ОтветJSON(200, ОшибкаRPC(Ид, -32601, "Method not found: " + Метод));
	КонецЕсли;

	ОтветRPC = Новый Соответствие;
	ОтветRPC.Вставить("jsonrpc", "2.0");
	ОтветRPC.Вставить("id", Ид);
	ОтветRPC.Вставить("result", Результат);
	Возврат ОтветJSON(200, ОтветRPC);

КонецФункции

#КонецОбласти

#Область MCP

Функция Инициализация(Параметры)

	ВерсияПротокола = "2025-06-18";
	Если ТипЗнч(Параметры) = Тип("Соответствие")
		И ЗначениеЗаполнено(Параметры.Получить("protocolVersion")) Тогда
		ВерсияПротокола = Параметры.Получить("protocolVersion");
	КонецЕсли;

	Возможности = Новый Соответствие;
	Возможности.Вставить("tools", Новый Соответствие);

	Сервер = Новый Соответствие;
	Сервер.Вставить("name", "bilem");
	Сервер.Вставить("version", ВерсияРасширения());

	Результат = Новый Соответствие;
	Результат.Вставить("protocolVersion", ВерсияПротокола);
	Результат.Вставить("capabilities", Возможности);
	Результат.Вставить("serverInfo", Сервер);
	Результат.Вставить("instructions",
		"Bilem — агент для 1С:Бухгалтерии для Казахстана. Только чтение, учёт не изменяет.");
	Возврат Результат;

КонецФункции

Функция СписокИнструментов()

	Схема = Новый Соответствие;
	Схема.Вставить("type", "object");
	Схема.Вставить("properties", Новый Соответствие);

	Инструмент = Новый Соответствие;
	Инструмент.Вставить("name", "whoami");
	Инструмент.Вставить("description",
		"Кто я: пользователь 1С, база, конфигурация, версии платформы и расширения, организация, время ответа. "
		+ "Для проверки подключения к 1С.");
	Инструмент.Вставить("inputSchema", Схема);

	Список = Новый Массив;
	Список.Добавить(Инструмент);

	Результат = Новый Соответствие;
	Результат.Вставить("tools", Список);
	Возврат Результат;

КонецФункции

Функция ВызовИнструмента(Параметры)

	Имя = Неопределено;
	Если ТипЗнч(Параметры) = Тип("Соответствие") Тогда
		Имя = Параметры.Получить("name");
	КонецЕсли;

	ЕстьОшибка = Ложь;
	Если Имя = "whoami" Тогда
		Текст = СтрокаJSON(КтоЯ());
	Иначе
		Текст = "Неизвестный инструмент: " + Строка(Имя);
		ЕстьОшибка = Истина;
	КонецЕсли;

	Блок = Новый Соответствие;
	Блок.Вставить("type", "text");
	Блок.Вставить("text", Текст);

	Содержимое = Новый Массив;
	Содержимое.Добавить(Блок);

	Результат = Новый Соответствие;
	Результат.Вставить("content", Содержимое);
	Результат.Вставить("isError", ЕстьОшибка);
	Возврат Результат;

КонецФункции

#КонецОбласти

#Область Инструменты

Функция КтоЯ()

	Конфигурация = Новый Соответствие;
	Конфигурация.Вставить("name", Метаданные.Синоним);
	Конфигурация.Вставить("version", Метаданные.Версия);

	Расширение = Новый Соответствие;
	Расширение.Вставить("name", "bilem");
	Расширение.Вставить("version", ВерсияРасширения());

	Данные = Новый Соответствие;
	Данные.Вставить("as_of", XMLСтрока(ТекущаяДатаСеанса()));
	Данные.Вставить("user", ИмяПользователя());
	Данные.Вставить("user_full_name", ПолноеИмяПользователя());
	Данные.Вставить("config", Конфигурация);
	СистемнаяИнформация = Новый СистемнаяИнформация;
  Данные.Вставить("platform", СистемнаяИнформация.ВерсияПриложения);
	Данные.Вставить("extension", Расширение);
	Данные.Вставить("org", НаименованиеОрганизации());
	Данные.Вставить("note", "Bilem не влияет на учёт: только чтение и непроведённые документы.");
	Возврат Данные;

КонецФункции

// Первая непомеченная на удаление организация. Нет прав или справочника — null, а не ошибка.
Функция НаименованиеОрганизации()

	Попытка
		Запрос = Новый Запрос(
			"ВЫБРАТЬ ПЕРВЫЕ 1
			|	Организации.Наименование КАК Наименование
			|ИЗ
			|	Справочник.Организации КАК Организации
			|ГДЕ
			|	НЕ Организации.ПометкаУдаления
			|
			|УПОРЯДОЧИТЬ ПО
			|	Организации.Наименование");
		Выборка = Запрос.Выполнить().Выбрать();
		Если Выборка.Следующий() Тогда
			Возврат Выборка.Наименование;
		КонецЕсли;
	Исключение
		Возврат Неопределено;
	КонецПопытки;

	Возврат Неопределено;

КонецФункции

#КонецОбласти

#Область Служебные

Функция ВерсияРасширения()

	Попытка
		Возврат Метаданные.HTTPСервисы.bilem.РасширениеКонфигурации().Версия;
	Исключение
		Возврат "0.1.0";
	КонецПопытки;

КонецФункции

Функция ТокенИзЗаголовка(Запрос)

	Заголовок = Запрос.Заголовки.Получить("Authorization");
	Если Заголовок = Неопределено Тогда
		Заголовок = Запрос.Заголовки.Получить("authorization");
	КонецЕсли;
	Если Заголовок = Неопределено Или Не СтрНачинаетсяС(НРег(Заголовок), "bearer ") Тогда
		Возврат "";
	КонецЕсли;
	Возврат СокрЛП(Сред(Заголовок, 8));

КонецФункции

Функция ТокенВерен(Токен)

	Если Не ЗначениеЗаполнено(Токен) Тогда
		Возврат Ложь;
	КонецЕсли;
	Эталон = СокрЛП(Константы.BilemТокен.Получить());
	Возврат СтрДлина(Эталон) >= 32 И Токен = Эталон;

КонецФункции

Функция ОтветJSON(КодСостояния, Данные)

	Ответ = Новый HTTPСервисОтвет(КодСостояния);
	Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
	Ответ.Заголовки.Вставить("Cache-Control", "no-store");
	Ответ.УстановитьТелоИзСтроки(СтрокаJSON(Данные), "UTF-8", ИспользованиеByteOrderMark.НеИспользовать);
	Возврат Ответ;

КонецФункции

Функция СтрокаJSON(Данные)

	Запись = Новый ЗаписьJSON;
	Запись.УстановитьСтроку(Новый ПараметрыЗаписиJSON(ПереносСтрокJSON.Нет));
	ЗаписатьJSON(Запись, Данные);
	Возврат Запись.Закрыть();

КонецФункции

Функция ПрочитатьJSONИзСтроки(Строка)

	Чтение = Новый ЧтениеJSON;
	Чтение.УстановитьСтроку(Строка);
	Результат = ПрочитатьJSON(Чтение, Истина);
	Чтение.Закрыть();
	Возврат Результат;

КонецФункции

Функция ОшибкаПростая(Код)

	Ошибка = Новый Соответствие;
	Ошибка.Вставить("error", Код);
	Возврат Ошибка;

КонецФункции

Функция ОшибкаRPC(Ид, Код, Текст)

	Ошибка = Новый Соответствие;
	Ошибка.Вставить("code", Код);
	Ошибка.Вставить("message", Текст);

	Ответ = Новый Соответствие;
	Ответ.Вставить("jsonrpc", "2.0");
	Ответ.Вставить("id", Ид);
	Ответ.Вставить("error", Ошибка);
	Возврат Ответ;

КонецФункции
```
