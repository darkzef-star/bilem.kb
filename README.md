# bilem.kb — база знаний Bilem

Приватный репо. Сайт собирает Mintlify из `.mdx`-файлов при каждом коммите в `main`.

- Навигация — `docs.json`; новая страница = файл `.mdx` + строка в `navigation`.
- Предпросмотр локально: `npx mint dev` → http://localhost:3000
- Как писать и что куда — `process/kak-pisat.mdx`.
- Не кладём: пароли, токены, ключи, данные реальных клиентов.
